# member1_nlp

Project scaffold for incident-report NLP preprocessing, feature extraction, model training, prediction, and entity extraction.

## Structure

- `data/raw/` for source CSV files
- `data/processed/` for cleaned datasets
- `notebooks/` for exploration notebooks
- `src/` for Python pipeline modules
- `models/` for saved model artifacts
- `outputs/` for generated reports and predictions

## Next Steps
